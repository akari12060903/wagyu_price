# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

**リモートリポジトリとは**
ネット上に配置してある複数人で共有するためのリポジトリ。

**ローカルリポジトリとは**
開発者たちが一人ひとり使用するためにそれぞれのPC上に配置するリポジトリ。

## プッシュとマージの違いは何でしょうか？

**プッシュとは**
ローカルで編集した内容をリモートにアップする作業のこと。

**マージとは**
現在いるブランチに指定したブランチの編集内容を読み込ませるコマンド。


## コミットとプッシュの違い

**プッシュとは**
ローカルで編集した内容をリモートにアップする作業のこと

**コミットとは**
セーブポイントを残すことのできるコマンド

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

どのような編集を行なったのかわかりやすく記述するのが最適

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

**ローカルでマージするフロー**
1. 作業ブランチで編集内容のadd、commit、pushまで完了させる。
2. masterブランチに移動してgit mergeを実行し、作業ブランチの変更履歴をmasterに取り込む。

**プルリクエストでマージするフロー**
1. 作業ブランチで編集内容のadd、commit、pushまで完了させる。
2. GitHubにてマージ依頼のプルリクエストを作成し、レビュワーにレビューをしてもらう。
3. レビューが完了したら、レビュワーがマージを実行する。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

**コンフリクトが発生した際の対処法**
* 先にマージした編集内容を取り込む。
* 後からマージしようとした編集内容を取り込む。
* どちらの編集内容も取り込む。
